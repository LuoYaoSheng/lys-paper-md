## 3. 主题归并：体验问题全景

| # | 场景 | P4 编号 | UF 升级 | 用户感受 |

（源：P4 §一 F-05；USER_FLOW_REVIEW §三 UF-02；PERMISSION_REVIEW PM-01）

### 3.2 数据安全族（评审最高优先级）

1. **UF-02 解码失败→欢迎文本→autosave 覆盖**：全部静默失败中后果最重的一条，完整数据损失链（详见 `docs/03_flow/BUSINESS_FLOW.md` §2.1）。
2. **UF-05 首存迁移非事务式**：文本与文件双失且 ⌘Z 不可恢复（BUSINESS_FLOW §2.3）。
3. **UF-03 外部修改静默覆盖**：多工具写作场景外部工作丢失（BUSINESS_FLOW §2.4；时序见 `SEQUENCE_DIAGRAMS.md` 图 5）。
4. **UF-01 untitled 无自动保存/崩溃恢复**：新用户最脆弱时段恰无保护。
5. **UF-08 Sudden/Automatic Termination 声明**：放大丢失窗口，与「关窗驻留」语义张力。

## 6. 综合结论

1. 产品主链路（开写/编辑/保存/导出）**骨架健康**，全部最短路径可达；无结构性页面增删需求（与 IA 分册结论互证）。
2. 体验债集中在两处：**失败不可见**（B5 族 7 点 + UF 升级）与**数据安全缺口**（UF-01/02/03/05 四条 B 级链，其中 UF-02 为最高风险）。
3. 修复成本排序：反馈类（B5/B6）低成本低风险，应最先落地；数据安全类（UF-02/05/03）涉及保存管线重构，属 M1-M3 里程碑核心；UF-07/08 等待用户决策。
4. 全部 B 类已在 `prototype/v1-new/app-prototype.html` 呈现修复后规格并逐项注明旧行为（验收见 `docs/09_test/V1_ACCEPTANCE.md`）。
